1.Distinguish between a "pointer to a constant" & "constant pointer"

    - Pointer to a constant:
    + It's a pointer point to a constant item
    + The data that a pointer point to cannot change
    + The pointer can change itself

    - Constant pointer:
        + It's a pointer itself that is constant
        + The data that a pointer point to can change
        + It must be initialized with an address and after that it cannot point to anything else.

    - const int *ptr1 // ptr1 is a pointer to constant integer
    - int *const ptr2 // ptr2 is a constant pointer

12. Write a C++ function called exchange that takes two integer pointer variables and exchanges
the values in those variables

"
    void exchange(int *a, int *b)
    {
        int temp;
        temp = *a;
        *a = *b;
        *b = temp;
    }
"

14. Consider the following C++ code fragment. Identify the syntax/logic/semantic errors in the code 
    fragment if there is any. Suggest the correction for each of the errors.
    "
    int *findMax(int *a, int *b) {
    int max;
    if(*a > *b) 
    max=*a;
    else 
    max = *b;
    Return &max;
    }
    
    int main() {
    int x=7, y=15, max;
    max = findMax(&x, &y);
    return 0;
    }
    "

    - syntax error : 
        + "Return" --> "return"

    - semantic error :
        + In function "findMax", it will return address of "max". In stack, when function "findMax" finishes 
        local variable "max" will be deleted so the block of memory is invalid. Therefore, when the address
        returning to variable pointer "max" in main will be invalid and its value can be rubbish.
        + Correcting: findMax is function that return an integer instead of an address.
